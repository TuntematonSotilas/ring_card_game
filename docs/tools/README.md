# Tools

> Recommended software for producing game content (art, audio). Not to be confused with the repository's `tools/` folder, which will hold project scripts ([technical/02-project-structure.md](../technical/02-project-structure.md)).
> Status: Draft · Last updated: 2026-10-09

| Document | Content |
|----------|---------|
| [Art tools](art-tools.md) | Illustration, card frames, icons, UI mockups, paper prototypes |
| [Audio tools](audio-tools.md) | Leitmotif arrangement (MIDI), orchestration, SFX, export to Godot |

## Recommended starter kit (all free)

| Domain | Tool |
|--------|------|
| Illustration | Krita |
| Vector (frames, icons) | Inkscape |
| UI mockups | Figma (free tier) or Penpot |
| Music writing | MuseScore Studio + Muse Sounds |
| Music production | Reaper (paid, long evaluation period) or LMMS |
| Orchestral samples | Spitfire LABS, BBC Symphony Orchestra Discover |
| Sound editing | Audacity |
| Game engine | Godot 4.7.2 |
| Code editor | VS Code + *godot-tools* extension (GDScript language server) |
